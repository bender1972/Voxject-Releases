# Voxject für Windows – Releases

Hier liegen die fertigen Pakete von Voxject (Diktier-App für Windows 11, 64 Bit): unter **Releases** rechts die Datei `Voxject-<Version>-win-x64.zip` herunterladen, entpacken, `Voxject.exe` starten. Installation und Deinstallation stehen in `ANLEITUNG.txt` im ZIP.

Eine installierte Version aktualisiert sich selbst: *Einstellungen → Über → Auf neue Version prüfen*. Neben jedem ZIP liegt die SHA-256-Prüfsumme (`.sha256`), die Voxject vor dem Installieren prüft.

Der Quellcode liegt in einem privaten Repository. Voxject ist ein Windows-Nachbau der macOS-App Blitztext (MIT) für den privaten Gebrauch.
